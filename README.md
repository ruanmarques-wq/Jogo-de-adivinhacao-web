# Jogo de Adivinhação de Palavras

Projeto desenvolvido na disciplina de Desenvolvimento de Aplicações Web I, do IFPB.

## Integrante
- Bruno Ruan

## Como jogar
1. Observe a categoria da palavra.
2. Digite uma letra no campo indicado.
3. Clique em **Tentar** ou pressione **Enter**.
4. As letras corretas aparecem na palavra.
5. Cada letra errada diminui uma tentativa.
6. Não repita letras que já foram utilizadas.
7. Descubra a palavra antes de acabarem as seis tentativas.

Clique em **Nova partida** para começar novamente.

## Tecnologias
- HTML5
- CSS3
- JavaScript

## Funcionalidades
- Escolha aleatória entre 15 palavras.
- Palavra escondida por traços.
- Categorias para ajudar o jogador.
- Controle de seis tentativas.
- Exibição das letras utilizadas.
- Bloqueio de letras repetidas.
- Mensagens de vitória e derrota.
- Botão para iniciar uma nova partida.
- Uso da tecla Enter para enviar uma letra.
